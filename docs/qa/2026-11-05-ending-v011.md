# v0.1.1 片尾验收

## 画面与时序

- 新增同一坐姿机位的专注／惊讶关键帧；2–7 秒与 7–12 秒各占 5 秒。帧切换为互斥显示，避免两张脸交叉叠化。
- 镜像终端在前景，人物与椅背、键盘及书房一起出现在屏幕对面。先退出显示面，再以同一几何投影拉远到房间显示器；地球与片名使用缓入缓出。
- 无进度条；支持减少动态、暂停、跳过与重播。图像先解码再启动时钟。

## 检查结果

- `node --test`：101/101 通过。新增测试覆盖两帧边界、横竖屏投影、照片独占显示、减少动态、暂停、解码失败、加载期间撤回、关闭清理、无照片重播。
- 使用合成 ImageCapture 输入检查真实适配器流程：不勾选保留时无结尾照片；勾选时只存标签页会话，返回 ephemeral 图像；每次停止采集轨道并关闭位图；forget 清理会话存储与片尾图片节点；持久化上下文不包含照片。
- 浏览器在隔离端口 8916 的时钟受控夹具中，检查专注／惊讶帧、10.9 秒合成照片、撤回即时恢复、16 秒拉远与 20 秒房间；不调用真实摄像头。合成照片带有明显标识，不是用户照片。
- 最终单 HTML 在独立端口 8917 执行实际主线并提交结局，检查真实暂停／继续、两帧选择、内嵌图像、关闭清理。`input[type=range]` 为 0，测试控件为 0，浏览器 error 日志为空。
- 测试没有修改玩家已有站点存档。单文件不含测试夹具、合成照片或运行时数据。
